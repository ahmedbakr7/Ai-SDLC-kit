# DESIGN.md

Tokens and rules every page follows. Pages never use raw colours or ad-hoc spacing.

| Token | Value | Use |
|---|---|---|
| `--fg` | `#1a1a1a` | body text |
| `--muted` | `#5c5c5c` | secondary text |
| `--ok` | `#1d6b3a` | refunded, received |
| `--warn` | `#8a5a00` | requested, approved |
| `--bad` | `#a12020` | rejected |
| `--space-1..4` | `4/8/16/32px` | the only spacing scale |
