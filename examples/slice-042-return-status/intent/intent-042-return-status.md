# Intent 042 — return status

Shoppers need to see whether an order has an open return, and in which state, without calling support.

## Outcome

On the order detail page, show a return-status chip when a return exists for that order.

## Non-goals

- Starting a return from this page
- Refund amount math
- Carrier tracking deep-links
