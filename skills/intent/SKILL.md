# Play: intent

Write `intent/intent-NNN-<slug>.md` from the template with the human.

1. **Problem** in the user's words, with evidence (numbers, quotes, tickets). No
   solution vocabulary ("add a button") in this section.
2. **Outcome**: what is true for the user afterwards, observable.
3. **Out of scope**: the adjacent things people will assume are included. Be generous.
4. **Open questions** as `[OPEN: ...]`. If research is needed, ask the human to run
   the research play and wait for its brief.
5. Keep it under one page. Stop with `status: draft`; only a human sets `accepted`.
