# Pinned craft skills

Format: `name  src=<git-url>@<sha-or-tag>  used-by=<command>  notes`

Example (delete when you add real pins):

```
# playwright  src=https://github.com/example/skills@abc1234  used-by=/test  notes=e2e runner idioms
```

No entries yet. Add a line whenever you vendor a skill into `skills/vendor/<name>/`.
